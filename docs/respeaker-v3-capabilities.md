# reSpeaker Mic Array v3.0 — 기계 성능으로 대체하는 것들

작성일: 2026-08-24. 출처: Seeed 공식 위키(respeaker_mic_array_v3.0) + 이 장비
실측(devlog 2026-08-13·08-24). 장치: XVF-3000, 마이크 4개, 6채널 펌웨어,
16kHz, 3.5mm 재생 출력.

## 원칙

**reSpeaker 는 항상 있다.** 없으면 다른 장치로 조용히 폴백하지 않고 시끄럽게
실패한다 — 폴백은 AEC·VAD·방향이 전부 조용히 깨진 채 도는 것이므로 더
위험하다. DSP 설정 쓰기는 동결(D7, respeaker-dsp-config.md), 상태 읽기는 자유.
동결의 승인된 예외 1건: AGCDESIREDLEVEL 을 노드 기동 시 0.010 으로 쓴다
(2026-08-28 사용자 결정, `dsp_state.apply_agc_desired_level` — 근거·범위는
그 모듈 주석). 다른 파라미터 쓰기는 여전히 금지.

| **빔포밍** 화자 자동 조준 | 방향별 마이크 선택 로직 | ✅ 자동 (ch0) |

## 실측으로 확인된 대체 효과 (2026-08-24)

- 뮤트 제거: 함정 문장("비상 정지 버튼…") 오탐 0, TTS 중 "멈춰" 14/14 인식.
- AEC 실효: 사람이 로봇 말 중에 외친 "멈춰"의 whisper 전사가 **'멈춰' 한 단어**
  — 로봇 목소리가 한 글자도 안 섞임.
- SPEECHDETECTED: 로봇 단독 재생 중 0.0% (자기 메아리 완전 면역), 사용자
  발화 중 47.6% — barge-in 방아쇠로 채택.
- DOA: 화자 위치 구분 가능(사용자 236°±4° vs 옆사람 166°±16°). 단 로봇이
  말하는 동시 발화 중에는 방향이 섞이므로(217° 실측) 부채꼴은 ±15° 로 좁게.

## 남은 활용 계획

1. 🔜 **말끝 판정을 SPEECHDETECTED 로** — 소리 크기(RMS)는 약한 어미를 자르고
   소음에는 안 닫힌다. 끝판정 지속시간·창 길이는 실사용 측정으로 확정 [TARGET].
2. 🔜 질문 청취 창을 시나리오 6.4의 확인 대기(30초)와 일치.
3. 💡 GAMMAVAD_SR(VAD 민감도)은 조절 가능한 쓰기 파라미터지만 D7 동결 —
   바꾸려면 팀 합의 + 웨이크워드 학습 분포 호환성 검토.
