# 빔포밍 회전 — 앱에서 바로 켜고 끄기 (2026-11-19)

## 목적

2026-10-06 팀 요청으로 끈 **호출 방향 회전**(`VICA_WAKE_DOA_TURN`)을 다시 쓴다.
관리자가 앱 대시보드 '주행 설정' 칸에서 음성 재시작 없이 바로 켜고 끈다.
앱 이름은 **빔포밍 회전**(사용자 결정).

- 켜짐: 대기(IDLE) 중 "비카야"가 온 방향(DOA)을 `/vica/wake_doa` 로 미션에 보낸다 →
  `SpinInPlace` 회전, 손잡이 쪽(180±45°)이면 돌지 않고 바로 접근 질문.
- 꺼짐: 방향은 로그(`🧭 호출 방향 N°`)에만 남기고 미션에 보내지 않는다 → "네?"+청취만.
- 방향 읽기 자체는 끄지 않는다. 끼어들기 방향 관문(`VICA_USER_DOA_CENTER=180±60`)과
  화자 추적은 그대로.

배경: 마이크를 지면 1.17 m 에 전보다 높게 다시 달았다(사용자 11-19).
장착이 바뀌었으므로 `docs/beamforming_doa_facts.md`(루트) §11 에 따라 방향 기준을 다시 잰다.

## 하지 않는 것

- 시끄러운 곳에서 방향이 틀리는 문제(10-06 끈 원인) 개선
- 칩(XVF3000) 설정 변경, XVF3800
- 재부팅·음성 재시작 뒤에도 앱에서 고른 값 유지
- 미션·모드 노드 수정

## 방식 (사용자 선택: A)

| | 방식 | 판단 |
|---|---|---|
| **A** | 음성 노드에 SetBool 서비스 + latched 상태 토픽, 앱이 직접 부름 | **선택.** 즉시 적용·재시작 없음·주행 중에도 변경. 전방 초음파 스위치(11-18)와 같은 틀 |
| B | 모드 노드가 `.env` 를 고치고 ⑫ 재시작 | 재부팅 유지. 대신 바꿀 때마다 음성 약 10 s 끊김, 주행 중 불가, 세 저장소 수정 |
| C | A + 고른 값 파일 저장 | `.env` 와 저장 파일 중 어느 쪽을 따를지 규칙이 하나 더 생김 |

## 설계

### 음성 `src/ros_wakeword_node.py`

- 서비스 `/vica/wake_doa_turn/enable` (`std_srvs/SetBool`): `_wake_doa_turn` 을 바꾸고
  상태를 다시 발행한다. 응답 `success=True`, message '빔포밍 회전을 켰습니다' / '빔포밍 회전을 껐습니다'.
- 상태 `/vica/wake_doa_turn/enabled` (`std_msgs/Bool`, RELIABLE·TRANSIENT_LOCAL, depth 1):
  기동 때 한 번, 바뀔 때마다 발행.
- 기동 값은 지금처럼 `.env` `VICA_WAKE_DOA_TURN`(없으면 off).
- 값은 마이크 스레드(`_publish_wake_doa`)가 읽고 ROS 콜백이 쓴다 — bool 하나의 대입이라 잠금 없이 둔다.
- 회전 중에 꺼도 이미 보낸 회전은 끝까지 간다(한 번 보내면 미션 몫).

### 앱 (`VICA_Supervisor`, 운영 `after_feedback_waiting`)

- `supervisor_provider.dart`: 상태 구독 + 서비스 호출. 전방 초음파 스위치 코드와 같은 모양.
  상태를 못 받았으면 `null`(모름).
- `drive_nodes_card.dart`: '카메라 감지' 줄 아래, 구분선 뒤 '빔포밍 회전' 줄.
  캔버스 '앱 UI 사전확인' 101번 보드 그대로 —
  켜짐 '켜짐'(초록) / 꺼짐 '잠시 꺼짐' + 경고 칸 '회전 꺼짐 · 불러도 돌지 않음 · 음성 다시 켜면 켜짐' /
  모름 '음성 꺼짐 · 바꿀 수 없음' + 스위치 잠금. 아이콘 나침반(`explore`), 끄면 `explore_off`.
  누른 뒤 알림은 서비스 응답 문구 그대로.

### 시험

- 음성: 서비스가 값을 바꾸고 상태를 발행하는지, 꺼지면 `/vica/wake_doa` 를 보내지 않는지.
- 앱: 카드 세 상태(켜짐·꺼짐·모름) 위젯 시험.

## 실기 순서

1. **방향 기준 재측정** — 회전을 끈 채 정면·손잡이·좌우를 걸으며 부르고 `🧭 호출 방향` 을 본다.
   로봇은 움직이지 않는다. 기준: 정면 ≈0°(09-10: 11.8°), 손잡이 180°(09-01: 172~180°),
   부호 `wake_doa_sign=+1.0`(걷기 관찰).
2. 기준이 맞으면 앱에서 켜고 회전 실기(주변 비움).
3. 통과하면 `.env` `VICA_WAKE_DOA_TURN=on`.

기준이 틀어졌으면 `VICA_USER_DOA_CENTER`·`wake_doa_sign` 수정은 따로 사용자에게 묻는다.

## 저장소·브랜치

- 음성 `after_feedback_waiting`. 앱은 운영 `after_feedback_waiting` — 도킹·수동 주행 세션이 운영 브랜치에
  합치기를 끝낸 뒤 그 위에서(11-19 도킹 세션 조율, `supervisor_provider.dart` 겹침). 다른 세션 작업이 함께 있어 내 파일만 커밋.
- 실기 전 푸시·dev 머지 없음. 웹·APK 빌드는 주행 묶음이 꺼져 있을 때만(11-17 사고).
