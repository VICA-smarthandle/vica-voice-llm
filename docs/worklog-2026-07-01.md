# VICA 작업 로그 — 2026-07-01

## 요약
음성 파이프라인을 ROS2 그래프로 완성하고, 커스텀 메시지·멀티턴 수정·Jetson 이식 준비까지
마친 뒤 GitHub(private)에 올렸다.

## 한 일
1. STT/TTS 를 ROS2 노드로 분리 (`ros_stt_node`, `ros_tts_node`) — 완전한 음성 그래프
2. launch 파일 (`vica_voice.launch.py`) — 노드 일괄 실행
3. 커스텀 메시지 (`vica_interfaces`: `VicaIntent.msg`, `RobotState.msg`) + `colcon build`
4. 노드를 `String+JSON` → 커스텀 msg 로 전환 (`ros_convert.py` 변환)
5. 멀티턴 버그 수정:
   - `ros_node.py` 에 대화 `history` 추가 (ROS2 에서 멀티턴이 안 되던 것)
   - `is_confirmation`/`confidence` 를 `Optional` 로 (gemma 의 null 응답 파싱 실패 방지)
6. LLM/STT 백엔드 환경변수화 (`.env` 로 PC 클라우드 ↔ Jetson 로컬 전환)
7. Jetson 이식 가이드 (`docs/jetson-setup.md`) + `.env.example`
8. state machine / robot_state 발행 스텁 (개발 데모용) + launch 통합
9. git 초기화 + GitHub private repo push (`TONY0043/vica-voice-llm`)

## 주요 발견 / 결정
- ROS2 노드에 `history` 가 빠져 멀티턴이 안 됐음 → 실기 테스트로 발견 후 수정.
- gemma 가 `is_confirmation` 을 `null` 로 줄 때가 있음 → `Optional` 로 방어.
- Jetson: Ubuntu 22.04 / Python 3.10 / ARM64, JetPack 6.2.1, LLM 은 로컬 `gemma4:e2b` 예정.
- 이식은 "복사"가 아니라 "재구축": `.venv` 재생성 + `colcon` 재빌드 + `.env` 새로 작성.

## 실행법 (요약)
- CLI: `python -m src.main` (마이크: `VICA_STT=1 python -m src.main`)
- ROS2: `ros2 launch launch/vica_voice.launch.py` + 별도 터미널 `python -m src.ros_stt_node`
- 커스텀 msg 사용 시 실행 전: `source ros2_ws/install/setup.bash`
