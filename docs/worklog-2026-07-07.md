# VICA 작업 로그 — 2026-07-07

## 요약
실기 음성 테스트(USB 마이크 + 에어팟)를 완료하고, STT/TTS 를 CUDA 로 가속해
한 턴 응답을 ~5초로 줄였다. 이어서 **Phase 4(상시 긴급어 감지)** 를 구현하고
"멈춰" 외침이 ROS2 `/vica/emergency` 토픽까지 전달되는 것을 실기 검증했다.
마지막으로 **Phase 5(FastAPI + SQLite 목적지 백엔드)** 까지 완료했다.

## 한 일

### 1. 실기 음성 테스트 (USB 마이크 ABKO MP3300 + 에어팟)
- 에어팟은 HFP 프로파일만 잡힘 (A2DP 없음) — 음성 안내엔 충분해서 그대로 사용
- TTS 재생 / 마이크 녹음 / whisper 한국어 인식 모두 정상
- 전체 파이프라인(`VICA_STT=1 python -m src.main`) 실기 동작 확인

### 2. STT CUDA 가속: small/CPU 5.2초 → medium/CUDA 1.4초
- pip 의 ctranslate2 ARM64 휠은 CPU 전용 → **CUDA(sm_87) 소스 빌드** (~10분)
- sudo/LD_LIBRARY_PATH 없이 동작하도록 rpath + lib 복사 방식으로 `.venv` 설치
- small 은 "식당"→"직당" 오인식이 있어 **medium 채택** (더 정확한데도 3.7배 빠름)
- 빌드 산출물 `~/jetson-builds/` 보존, 재설치/재빌드 절차는 `docs/jetson-setup.md`

### 3. TTS CUDA 가속: 3.0초 → 0.3초
- Jetson AI Lab 의 `onnxruntime-gpu` 휠 설치 (빌드 불필요)
- supertonic 의 하드코딩된 CPU provider 를 `src/tts.py` 에서 CUDA 우선으로 패치
- CUDA 없는 환경(PC)은 자동 CPU 폴백 — 코드 호환 유지

### 4. Phase 4: 상시 긴급어 감지 (Always-on Emergency Path)
CLAUDE.md 지침대로 rule-based 우선 (openWakeWord 는 추후 별도 실험).

```text
마이크 상시 스트림 (2초 창, 0.5초 슬라이딩)
-> 음량 게이트 (조용하면 STT 생략)
-> whisper small/CUDA (~0.5초)
-> emergency_filter (LLM 없음)
-> EmergencyEvent -> /vica/emergency 발행
```

- `src/emergency_monitor.py`: 핵심 로직 + CLI 데모. 쿨다운(2초)으로 중복 방지
- `src/ros_emergency_node.py`: 감시 스레드 + `/vica/emergency` 발행
- `vica_interfaces/EmergencyEvent.msg` 추가 + colcon 재빌드
- launch 통합, unit test 5개 추가 (총 19개 통과)
- **실기 검증**: "멈춰" 외침 → 약 1초 내 토픽 수신 확인
- 안전 원칙: 감지·발행만 한다. 정지 실행은 Safety Supervisor / State Machine 몫

### 5. Phase 5: FastAPI + SQLite 목적지 백엔드
- `backend/db.py`: SQLite 저장소 (목적지를 JSON 으로 저장, 첫 실행 시 YAML 시드)
- `backend/app.py`: API 4개 — `GET /destinations`, `GET /destinations/search?query=`,
  `POST /destinations`(upsert), `PATCH /destinations/{id}/pose`(calibration 용)
- `destination_loader`: `VICA_DEST_API` 설정 시 API 조회, **실패하면 YAML 폴백**
  (백엔드 장애가 로봇 파이프라인을 멈추지 않게). 기본값은 기존 YAML 모드 유지
- 원칙: 파이프라인은 조회만, 목적지 추가·pose 수정은 관리자/calibration 도구 담당
- TestClient 기반 unit test 7개 (총 26개 통과)
- 실기 검증: 검색("407호"), pose 수정 -> 파이프라인 조회에 즉시 반영, 폴백 동작
- 백엔드 실행: `.venv/bin/uvicorn backend.app:app --port 8000`

### 6. 버그 수정
- `src/stt.py` 가 `.env` 를 스스로 로드하도록 수정 — LLM 파서를 거치지 않는
  진입점(emergency_monitor 등)에서 `VICA_STT_DEVICE=cuda` 가 무시되던 문제

## 주요 발견 / 결정
- 소스 빌드한 ctranslate2 는 **CPU int8 미지원** (OpenBLAS 만 링크) — Jetson 에선
  cuda/float16 만 쓰므로 문제없지만, CPU 폴백이 필요해지면 재빌드 필요
- `ros2 topic echo` 는 토픽이 아직 없으면 기다리지 않고 즉시 종료한다 —
  발행자를 먼저 띄우고 echo 를 걸어야 함 (실기 테스트 때 헛수고의 원인)
- whisper 는 잡음에 환청 텍스트를 만들 수 있음 ("구독과 좋아요...") —
  긴급어 매칭이라 실해는 없지만, 필요해지면 vad_filter 나 음량 게이트 강화로 대응
