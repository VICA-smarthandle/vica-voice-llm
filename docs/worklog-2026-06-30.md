src/stt.py                         # faster-whisper 한국어 음성 입력
src/ros_node.py                    # ROS2 Jazzy 노드
src/main.py                        # CLI (키보드/마이크 + TTS)
tests/test_destination.py          # 단위 테스트
tests/test_emergency.py            # 단위 테스트

## 핵심 설계 결정
- 이해·대화는 LLM, 결정·안전은 코드 — 목적지 확정은 코드가(agent tool 아님).
- 긴급어는 LLM 우회 — Ollama가 끊겨도 "멈춰"는 작동한다.
- 프로토타입은 클라우드(gemma4), 최종은 온디바이스 목표.
- ROS2는 문서엔 Humble이지만 실제 환경은 Jazzy.
- ROS2 메시지는 우선 std_msgs/String + JSON (커스텀 .msg 는 나중).
