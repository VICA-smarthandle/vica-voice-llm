# VICA 작업 로그 — 2026-07-02

## 요약
Jetson Orin NX 이식(`docs/jetson-setup.md`)을 실행해 완료했다. 로컬 LLM(gemma4:e2b)으로
전체 파이프라인이 동작하는 것을 검증했다. 단, intent 파싱 지연(14~20초)이 발견되어
다음 과제로 남았다.

## 한 일
1. apt 의존성 설치 (`python3-dev`, `portaudio19-dev`, `libportaudio2`, `espeak-ng`, `ffmpeg`)
2. `.venv` 재생성 — `requirements.txt` 전체 핀은 Python 3.10과 불일치(numpy 2.4.6,
   scipy 1.18.0 은 3.11+ 전용)해서, 가이드대로 핵심 패키지만 핀 없이 설치
   (numpy 는 2.2.6 으로 자동 선택됨). unit test 14개 전부 통과.
3. Ollama 0.31.1 설치 + `gemma4:e2b` (7.2GB) 다운로드
4. `.env` 작성 — 로컬 Ollama (`http://localhost:11434`, `VICA_LLM_MODEL=gemma4:e2b`)
5. CLI 파이프라인 검증 (비대화식):
   - 긴급어 "멈춰" → LLM 우회 즉시 차단 OK
   - "윤지영 교수님 사무실로 가줘" → `navigate` + 목적지 id 정확 매칭 OK
   - "지금 몇 층이야?" → `question` + robot_state 반영 답변 OK
6. `python3-colcon-common-extensions` 설치 + `vica_interfaces` colcon 재빌드 (ARM64)
7. ROS2 커스텀 msg 확인 — `ros2 interface show` + 파이썬 import OK

## 주요 발견 / 결정
- **intent 파싱 14~20초** — LLM 생성 속도 자체는 35 tokens/s 로 충분한데,
  목적지 목록이 든 긴 시스템 프롬프트의 prefill 이 병목으로 추정.
  개선 후보: 프롬프트 축소 → 더 작은 모델(qwen2.5:3b 등) → Ollama 프롬프트 캐시.
- 모델 첫 호출은 로드 포함 ~20초, 로드 후 단문 응답은 1.6초.
- 오디오 장치는 HDMI/내장(APE)만 인식됨 — **USB 마이크/스피커 미연결**.
  STT/TTS 실기 테스트는 장치 연결 후 가능.
- onnxruntime 의 "GPU device discovery failed" 경고는 Jetson iGPU 를 데스크톱
  방식으로 못 찾는 것일 뿐, CPU 추론 정상 — 무시해도 됨.

## 실행법 (Jetson)
- CLI: `.venv/bin/python -m src.main` (마이크: `VICA_STT=1`)
- ROS2: `source /opt/ros/humble/setup.bash && source ros2_ws/install/setup.bash` 후
  `ros2 launch launch/vica_voice.launch.py`
