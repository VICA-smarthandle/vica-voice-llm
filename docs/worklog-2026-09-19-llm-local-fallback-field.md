## 4. 결정·변경

- 결정 4 변경: "로그 + 앱 진단" → **"로그만"**. 이유는 2회차.
- 12초 예산: 최악 경로(6+7+3=16초)는 나오지 않았다. 와이파이 off 는 연결 오류가 즉시
  나서 6초를 안 기다린다. 공유기 WAN 만 끊기는 경우(6초 대기 + DNS)는 **미시험**.
- 로컬이 깨진 채 대피한 경우의 즉시 복귀(최종 검토 지적)는 **미결**. 스펙 변경 여부는
  사용자 판단.
